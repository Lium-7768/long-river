## 三、横向交叉核验结论

### 1. Q-ID 桥接可信度（Wikidata ↔ 库内）
- 已桥接：20,717 人
- 高可信（生卒 ±1年一致）：20,531
- 结论：**99.1% 高可信**，Wikidata 精确生卒与库内差异仅 0.4%

### 2. 正史卒年互证（正史全文 ↔ 库内）
- 宋史（北宋）一致率 **72.9%**，余为 CBDB 生年推定误差（卒年多正确）
- 报告详见 `史料互证报告.md`

### 3. 诗词作者消歧（chinese-poetry ↔ CBDB）
- poem_persons 消歧链接：318,076 条
- 修正同名作者误连（唐·朱庆余 vs 明·朱庆余 178首）
- 报告详见 `诗词核验报告.md`

### 4. 关系网络合理性
- 枢纽排名：朱熹2049 / 苏轼794 / 周必大754 / 刘克庄729（符合学术直觉）

## 四、已知局限（诚实声明）

- 生卒覆盖率 8–10%，为史料真实上限，不以推算填充
- 部分地名坐标仅精确到政区中心（CHGIS 提供区划点）
- 维基文库部分文本为 OCR 校勘版，偶有讹字

### 5.2 帝王世系（emperor）

- **419 位**帝王，含庙号/称号 + 本名 + 在位起止
- Wikidata 提供 401 位（P39=中国皇帝地位），正史补全 46 位庙号→本名
- 各朝：唐 30 / 清 21 / 汉（西）20 / 元 18 / 明 17 …
- 接入前端：L2 朝代页「帝王世系」块 + `GET /api/emperors?dynasty=`

### 5.3 关键人物可点击率（figures）

- **100%（603/603）**，从初值 3% 提升
- 解析链：name → aliases → 繁简归一(OpenCC) → 括注名 → emperor 庙号桥接
  → hist_alias 通称映射 → 维基新建人物

### 5.4 交叉核验

- 维基人物生卒 vs 库内：合理性校验（-3000<y<1950，卒≥生）
- 帝王在位年与朝代轴一致（Wikidata + 正史双源）
- 全部 368 个 figure personId 经 API 验证可达（0 失效）

### 5.5 诚实声明（本轮新增）

- 维基百科人物仅取**事实字段**（生卒/字/号/籍贯），不整段引文（CC BY-SA）
- 帝王在位年个别含 Wikidata 录入误差，已标注不确定项
- hist_alias 33 条为**人工审定**的公有领域正史映射
