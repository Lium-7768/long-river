## 三、重要鲁棒性修复：WebGL 崩溃

### 发现（headless 实测暴露的既有缺陷）

用无 GPU 的 headless 浏览器实测，发现**任何无法创建 WebGL 上下文的环境整页崩溃**：

```
THREE.WebGLRenderer: Error creating WebGL context.
→ ErrorBoundary 捕获 → 整页「页面渲染异常」白屏
```

**受影响页面**：首页（`RiverExperience`）、人物页（`KinshipGraph3D`）、疆域页（`TerritoryMap`）。

**触发场景**：老旧浏览器 / 用户禁用 WebGL / 部分移动端 / GPU 驱动故障 / 无头环境。

> 之前只测 HTTP 状态码未测真实渲染，故漏检 —— 本轮改用 CDP 取 `document.body.innerText` 才发现。

### 修复

新增 `web/lib/webgl.ts`（WebGL 能力探测，模块级缓存），三处 3D 组件加降级：

| 组件 | 无 WebGL 时回退 |
|---|---|
| `RiverExperience`（首页）| 22 朝 **2D 列表**（每朝可点，年份带纪年前缀）|
| `KinshipGraph3D`（亲属关系）| **2D 关系列表**（含类型图例，可点开每人）|
| `TerritoryMap`（疆域）| **省份标签列表** |

**原则固化**：3D 是**增强**，不是唯一路径。所有可读内容（文字/卡片）都有非 WebGL 通路。
